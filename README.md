# Clock Time 🕒

A lightweight, multi-platform utility application for tracking time across Windows, Android, and Web browsers.

---

## 🚀 Downloads & Installation

You can download official pre-built binaries directly from the [Releases Page](https://github.com/lie-kg1/clock-time/releases/tag/v1.0.0).

| Platform | Download / Access | Requirements |
| :--- | :--- | :--- |
| **Android** | `ClockTime-android.apk` | Android 8.0+ |
| **Windows 10/11** | `ClockTime-windows-setup.exe` | 64-bit Windows 10/11 |
| **Windows 7 (Legacy)** | `ClockTime-windows-legacy-x64-setup.exe` | 64-bit Windows 7 |
| **Browser (PWA)** | Web Version | Modern Web Browser |

---

## 🔒 Security & Installation Notes

* **Windows SmartScreen:** Because the installers are currently unsigned, Windows SmartScreen may show a warning on first launch. Click **More info** → **Run anyway** to proceed.
* **Android Unknown Sources:** When installing the `.apk` directly, grant permission to "Install unknown apps" from your web browser or file manager when prompted.
